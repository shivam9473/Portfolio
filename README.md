# Shivam Kumar — Portfolio

Desktop-style developer portfolio inspired by retro OS UIs. Built with vanilla HTML, CSS, and JavaScript.

**Live:** Enable GitHub Pages on this repo, or rename to `shivam9473.github.io` for `https://shivam9473.github.io`.

## Local preview

```bash
npx serve .
# or open index.html in a browser
```

## Structure

```
index.html      Main page
css/style.css   Styling
js/script.js    Window controls, dock nav, easter egg
```

## Deploy (GitHub Pages)

1. Push to `main`
2. **Settings → Pages → Source:** Deploy from branch `main`, folder `/ (root)`
3. For root URL `shivam9473.github.io`, rename this repo to `shivam9473.github.io`
