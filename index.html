01 · Full Stack / Backend

Fault-Tolerant Payment Ledger

Idempotent transfer API — correctness under retries & concurrency

  • Fault-tolerant money transfer REST API with durable Idempotency-Key storage and SHA-256 request fingerprints.
  • Concurrency safety via SELECT…FOR UPDATE row locking, lexical lock ordering, and atomic debit/credit in one PostgreSQL transaction.
  • React 19 + Vite ledger console (dashboard, transfer, activity, accounts) with paginated activity and problem+json errors.
  • Docker Compose packaging; deployable to Render (API + DB) and Vercel/Netlify (UI).
